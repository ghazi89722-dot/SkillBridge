# SkillBridge — Application Flow

## 1. Landing page (public, unauthenticated)
```
Hero (animated 3D skill-graph, lifecycle headline)
  → How It Works (Claim→Assess→Gap→Learn→Verify→Match→Apply strip)
  → For Students / For Industry / For Institutions / For Academicians (role explainer cards)
  → Flagship domain showcase (AYUSH sample role + explainable match preview)
  → Login / Sign Up
```
CTA hierarchy: primary = "Check My Skill Readiness" (student signup), secondary = "Explore Opportunities" (browse without login), tertiary = role-specific signup for Industry/Institution/Academician.

## 2. Auth & onboarding (per role)
- **Signup** → role selection → role-specific profile fields → email/OTP verification → dashboard.
- **Student onboarding:** education details (domain, program, college, year) → career interests → target role(s) → claim initial skills → prompted straight into first assessment.
- **Industry onboarding:** organization details, sector tag (mapped to a Domain), verification of organization identity (manual/admin-approved in MVP).
- **Institution onboarding:** institution profile, admin verification, bulk student roster import (CSV) optional.
- **Academician onboarding:** institution affiliation, subject area, research interests.
- **Ministry/NCISM:** admin-provisioned, read-only account, no self-signup.

## 3. Core student lifecycle (the product's central story)
```
Claim Skills
   ↓
Take Assessment (per claimed skill)
   ↓
Skill Result  → status: ASSESSED
   ↓
Skill Gap Analysis (vs a target role or a specific opportunity)
   ↓
Learning Recommendation (per gapped skill)
   ↓
Complete learning → Reassess
   ↓
Skill Result updates → status: VERIFIED (if threshold met) or NEEDS_IMPROVEMENT
   ↓
Digital Skill Passport updates automatically
   ↓
Explainable Opportunity Matches (ranked, with breakdown)
   ↓
Apply → Application state machine → Outcome
```

## 4. Application state machine
```
SAVED → APPLIED → UNDER_REVIEW → SHORTLISTED → INTERVIEW → SELECTED → COMPLETED
                         ↓
                     REJECTED   (terminal, any stage)
```
For internships specifically, `SELECTED` branches into: `STARTED → IN_PROGRESS → MENTOR_FEEDBACK → COMPLETED`.

## 5. Industry flow
```
Create Opportunity (role, description, eligibility, required skills + min proficiency, type, duration, remote/location)
   ↓
System auto-generates a ranked candidate shortlist (Matching Engine, explainable)
   ↓
Recruiter reviews per-candidate breakdown (matched skills / gaps)
   ↓
Shortlist → Interview → Select
   ↓
Post-internship: submit structured feedback (technical / communication / problem-solving ratings)
   ↓
Feedback feeds back into the student's verified skill history
```

## 6. Institution flow
```
Dashboard: total students, avg readiness, assessment completion rate
   ↓
Skill Gap Trends (institution-wide, by skill category)
   ↓
Drill into a specific skill gap → see affected students (aggregate, privacy-respecting)
   ↓
Create/manage a Training Program targeting that gap
   ↓
Track training impact on subsequent reassessment scores
```

## 7. Academician flow
```
Browse Collaboration Opportunities (FDP / guest lecture / mentorship / research / live project)
   ↓
Request / express interest
   ↓
Industry/Institution confirms
   ↓
Collaboration tracked on academician profile
```

## 8. Ministry / NCISM flow (read-only)
```
Login (admin-provisioned)
   ↓
National Skill-Gap Heatmap (by domain → state → institution, anonymized/aggregated)
   ↓
Drill into a specific skill category to see trend over time
   ↓
Export report (CSV/PDF) for curriculum review use
```
